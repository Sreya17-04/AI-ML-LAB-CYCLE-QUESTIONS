## Experiment Overview

### 1. Linear Regression – Part A

Implemented a linear regression model using a dataset to study the relationship between input features and a continuous target variable. The experiment includes model training, prediction, and evaluation using regression metrics.

### 2. Linear Regression using Synthetic Data – Part B

Generated a synthetic dataset and applied linear regression to understand the relationship between multiple features and a target variable.

### 3. Uniform Cost Search (UCS)

Implemented Uniform Cost Search to find a minimum-cost path between a starting node and a goal node in a weighted graph.

### 4. A* Search Algorithm

Implemented the A* search algorithm using path costs and heuristic values to find a path from a start node to a goal node.

### 5. Greedy First Fit Algorithm

Implemented a greedy bin-packing approach to understand how items can be assigned to bins according to their sizes and available capacity.

### 6. Breadth-First Search (BFS) and Depth-First Search (DFS)

- **BFS:** Traverses a graph level by level using a queue.
- **DFS:** Explores a path as deeply as possible before backtracking, using recursion or a stack.

### 7. Decision Tree Implementation

Built a decision tree classification model using Scikit-learn, demonstrating data preprocessing, model training, and interpretation of decision rules.

### 8. Random Forest and Support Vector Machine (SVM)

Implemented machine learning models, including Random Forest and Support Vector Regression (SVR), and evaluated their performance using regression metrics.

### 9. Logistic Regression

Implemented logistic regression for a classification task, focusing on dataset preparation, model training, predictions, and classification performance.

### 10. Artificial Neural Networks (ANN) and Clustering

Explored artificial neural networks for learning patterns in data and clustering techniques for grouping similar data points.
